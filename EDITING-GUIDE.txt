ABLESHINE WORLD - EDITING GUIDE
===============================

Live site: https://ableshine.com.au
The site publishes itself from GitHub (Ronnexus/ableshine-world, branch main).
Any change saved to GitHub is live in about a minute. No dragging or uploading to Netlify.

What's in here
- index.html         The whole 3D website (world, Sunny, tents, rooms, Connect, list view)
- data/site.json     ALL the content: contact details, every chapter, every photo
- media/             Logo, posters and event photos
- scripts/, netlify.toml, CLAUDE.md   Behind-the-scenes files. Leave these alone.


THE EASY WAY
------------
Send Claude the new details and photos and ask it to update the site.


EDIT IT YOURSELF ON GITHUB
--------------------------
1. Open github.com/Ronnexus/ableshine-world, then data, then site.json.
2. Click the pencil (Edit), make the change, then click "Commit changes".
3. Wait about a minute and refresh the live site.

Add a chapter: copy one block inside "events" and change the details.
  - "id": a unique name, e.g. "brimbank-2026-12-04"
  - "date": YYYY-MM-DD, or "" if not locked in (shows as Date TBC)
  - "color": purple, pink, teal (shows as blue) or amber (shows as yellow)
  - "posterId": path to the poster, e.g. "media/brimbank-poster.jpg"
  - "access": ONLY access features confirmed for that venue, e.g.
      ["Auslan interpreter", "Quiet zone", "Step-free entry", "Accessible toilets"]
    Leave it as [] until confirmed. The room then says details are being confirmed.
  - "previousDate": only if the date moved, e.g. "Wed 18 Nov" (shows a date-change banner)
  - "ticketUrl": the Eventbrite link. Shows "Get tickets" next to the chapter name, in the
    top bar (for the next event) and on the chapter's own page. Hidden once the date passes.
  - "facebookUrl": the Facebook event link.  "instagramUrl": the Instagram post link.
  Leave any link as "" if you don't have it yet; its button just won't show.
  Chapters sort by date, number themselves and get their status automatically.
  Each chapter also gets its own web page: ableshine.com.au/chapters/<id>/
  Use that link when sharing on Facebook and Instagram.

Your Facebook and Instagram pages go in the "config" section ("facebook", "instagram").
They show in Connect, in every page footer, and tell Google they belong to AbleShine.

Add event photos:
  1. Resize photos to about 2000px wide first (phone originals are too heavy).
  2. Upload them on GitHub into media/<chapter>/ (Add file, then Upload files),
     e.g. media/maribyrnong/photo-01.jpg
  3. Add one line per photo to "snapshots" in site.json:
     {"eventId": "maribyrnong-2026-08-28", "assetId": "media/maribyrnong/photo-01.jpg",
      "caption": "Magic show", "alt": "Kids laughing at the magician", "createdAt": 1}
  createdAt sets the order (1, 2, 3...). Always write the alt text: it is what
  screen-reader users hear.

A typo in site.json (a missing comma or quote) stops the chapters loading.
If the site shows "The chapters did not load", undo your last edit on GitHub.

Videos aren't in this version yet. Upload them to YouTube (unlisted) and we'll add
a video strip to each room in the next update.

Before sharing: check the phone number and add the website and email in site.json
("config" section). Get photo consent from everyone pictured.
